# Repository instructions

- Use English for file and directory names, code, comments, and repository documentation.
- Use Hugeicons for interface icons. Find and select icons from https://hugeicons.com/icons; do not substitute hand-drawn icons or another icon library. Prefer the free Stroke Rounded icons and keep their source names and license with the local SVG files.
- Maintain matching English and Polish website content in `content/en/` and `content/pl/`.
- Leave changes local for the user to review. Do not create commits or push unless the user explicitly requests it for the current changes.
- Validate site changes with the production Hugo build and `python scripts/check_site.py`.
