The NQ2 knowledge base gives instructions, examples, and decisions a permanent home.

## What you will find here

- **Documentation** — instructions and explanations of application behavior.
- **Integrations** — materials about connecting the application to services.
- **Snippets** — short code examples to reuse.
- **Blog** — updates and development notes.

The initial articles explain how to add content. Documentation for specific features will grow alongside the application.

## Knowledge stored in Markdown

Every article is a plain text file you can edit locally or on GitHub. The repository keeps the change history, and pushing to `master` triggers site publication.
